# SalimGPT Command Center v2 — ব্যবহার নির্দেশিকা

## ডকুমেন্টারি আইডিয়া থেকে অগ্রগতি

1. `Idea Vault → New Idea` থেকে যেকোনো বিষয় এক লাইনে সংরক্ষণ করুন।
2. ইচ্ছামতো বিবরণ, Review date, Priority, Tag যুক্ত করুন।
3. `Start Documentary` চাপলে স্বয়ংক্রিয় Production Checklist তৈরি হবে।
4. Planning, Research, Scripting, Vocal/Narration, Visual, Editing, Final Review ধাপে কাজ Done/Undo করুন।
5. নতুন Task, Deadline, Note ও Stage কাজ যুক্ত করুন।
6. `Documentary → Publishing Monitor`-এ প্রতিটি যুক্ত Profile-এর জন্য Published/Not Published/Not Applicable অবস্থা দেখুন।

## কেন্দ্রীয় প্রোফাইল তালিকা

`Social & Website Registry → Add Profile / Website` → Link + Label সংরক্ষণ করুন। YouTube চ্যানেল ১, চ্যানেল ২, Facebook পেজ ও SalimGPT ওয়েবসাইট আলাদা Profile। নতুন প্রোফাইলের জন্য পুরোনো ডকুমেন্টারি নতুন করে Edit করতে হয় না।

**এই অ্যাপ কোনো ওয়েবসাইটে পোস্ট করে না।** বাইরে করা প্রকাশনাকে আপনি এখানে Done হিসেবে চিহ্নিত করবেন।

## ব্যক্তিগত রিমাইন্ডার

`Reminders → Set Reminder` → শিরোনাম, তারিখ, সময়, lead alert, recurrence। App খোলা অবস্থায় ব্রাউজার অনুমতি থাকলে Notification আসে। কাজ আগেই শেষ হলে Done; পিছাতে Snooze। গুরুত্বপূর্ণ মিটিংয়ের জন্য `Export to Calendar (.ics)` করে ফোনের Calendar-এ Import করুন।

## যোগাযোগ, গবেষণা, লক্ষ্য

`Contacts`-এ ব্যক্তি/সংস্থার ফলোআপ তারিখ। `Research Library`-তে প্রমাণ, নোট ও URL। `Goals`-এ পরিমাণগত লক্ষ্য ও অগ্রগতি। `Reports`-এ সারসংক্ষেপ ও Activity Log-এ সাম্প্রতিক পরিবর্তনের ইতিহাস।

## নিরাপদ ডেটা সংরক্ষণ

প্রথমে অ্যাপের Settings-এ Private GitHub Token দিয়ে সংযোগ করুন। `Pending GitHub = 0` দেখালে আগে সংরক্ষিত তথ্য GitHub-এ রয়েছে। Browser Data Clear করলে নতুন সেশনে Token দিয়ে পুনরায় Connect করতে হবে, তারপর সব শেষ সফলভাবে Sync হওয়া তথ্য ফিরে আসবে। লোকাল Pending Records না থাকলেই ব্রাউজার ডেটা পরিষ্কার করুন।
