# SalimGPT Command Center V2 — ব্যবহার নির্দেশিকা

## ১. অ্যাপ চালু করা
`SalimGPT-Command-Center` রিপোজিটরিতে ফাইলগুলো আপলোড করুন। GitHub Pages চালু করলে আপনার মোবাইল ও কম্পিউটার উভয় জায়গাতেই ওয়েব অ্যাপ খুলবে। অ্যাপের তথ্য শুরুতে ব্রাউজারের IndexedDB-তে থাকে। অন্য ডিভাইসে একই তথ্য নিজে থেকে দেখা যাবে না; JSON Backup অথবা ঐচ্ছিক Supabase Cloud ব্যবহার করতে হবে।

## ২. নতুন ডকুমেন্টারি
**New Idea** চাপুন। শুধু নাম দিলেও নতুন Idea তৈরি হবে। চাইলে Description, Stage, Target Release Date, Priority, Language, Tags, Notes যুক্ত করুন। এভাবে ডকুমেন্টারি তৈরির কোনো সফটওয়্যার-নির্ধারিত সংখ্যা-সীমা নেই।

## ৩. বর্তমান পর্যায় ও কাজের চেকলিস্ট
Documentary List থেকে ডকুমেন্টারি খুলুন। ওপরের Current Stage নির্বাচন করে Idea / Scheduled / Research / Editing / Ready / Publishing / Published পর্যায় ঠিক করুন। Production Checklist-এ বাস্তব কাজ সম্পন্ন হলে টিক দিন। প্রয়োজনীয় অতিরিক্ত কাজ যুক্ত বা সংশোধন করতে পারবেন। Progress% টিক দেওয়া কাজ থেকে গণনা হয়, Stage নির্বাচন থেকে নয়।

## ৪. শিডিউল
একটি ডকুমেন্টারির Target Release Date নির্ধারণ করতে Edit চাপুন। প্রতিটি ধাপের জন্য আলাদা Start/Due Date দিতে **Stage Milestones** অংশের পেন্সিল আইকন ব্যবহার করুন। সময়সূচি পরিবর্তন সম্ভব। অ্যাপ শুধু পরিকল্পনা দেখায়, সময় পার হলেই নিজে থেকে ধাপ Complete করে না।

## ৫. SalimGPT Network
এখানে সব Facebook Page, YouTube Channel, Instagram, TikTok, X ও Website আলাদা নাম এবং URL-সহ যুক্ত করুন। একই প্ল্যাটফর্মে যত ইচ্ছা প্রোফাইল যুক্ত করা যাবে। Active প্রোফাইল সব ডকুমেন্টারির পৃথক Publishing Checklist-এ দেখাবে। প্রোফাইল পরিবর্তন/নিষ্ক্রিয় করা সম্ভব।

## ৬. প্রতিটি ডকুমেন্টারির পৃথক প্রকাশনা চেকলিস্ট
ডকুমেন্টারি খুলে Publishing Checklist দেখুন। প্রতিটি প্রোফাইলের ড্রপডাউনে **Not Published / Published / Not Applicable** থাকবে। নিজের হাতে Published চিহ্নিত করুন। পেন্সিল আইকনে ক্লিক করে তারিখ, পোস্ট URL ও নোট লিখতে পারবেন। একটি ডকুমেন্টারির টিক অন্যটিকে পরিবর্তন করে না। প্রকাশনার চেকলিস্ট যেকোনো Stage-এ দেখা যায়।

## ৭. সাপ্তাহিক পরিকল্পনা
ডিফল্ট লক্ষ্য **প্রতি সপ্তাহে ১টি প্রকাশনা**। Schedule পেজে আগামী ১২ সপ্তাহ এবং সেই সপ্তাহে নির্ধারিত ডকুমেন্টারি দেখা যাবে। ১টির বেশি নির্ধারণ করলেও অ্যাপ বাধা দেয় না। ডকুমেন্টারি নির্মাণ বা আইডিয়া সংগ্রহের কোনো অ্যাপ-নির্ধারিত সীমা নেই।

## ৮. Edit, Delete, Restore
তথ্য সংশোধনে Edit ব্যবহার করুন। Delete করলে Recycle Bin-এ যাবে, সেখান থেকে Restore সম্ভব। **Permanently Delete** করলে ফিরিয়ে আনা যায় না। পুরোনো নেটওয়ার্ক প্রোফাইলের প্রকাশনার ইতিহাস সংরক্ষণের চেষ্টা করা হয়।

## ৯. Backup
Settings → Export Backup: আপনার ডকুমেন্টারি, প্রোফাইল, চেকলিস্ট ও ইতিহাস নিয়ে JSON ফাইল তৈরি হবে। Import Backup করলে বর্তমান ওয়ার্কস্পেস প্রতিস্থাপিত হবে; তার আগে বর্তমান ডেটার JSON কপি ডাউনলোড হবে।

## ১০. ঐচ্ছিক ক্লাউড
`SalimGPT-Private-Data`-এর SQL migration Supabase-এ চালানোর পর Settings-এ Project URL ও Publishable Key দিয়ে লগইন করতে পারবেন। Cloud Check → Upload এবং প্রয়োজনমতো অন্য ডিভাইসে Download করুন। **এটি রিয়েল-টাইম অটো সিঙ্ক নয়।**

## সচেতনতা
SalimGPT Network-এর কোনো প্রোফাইল থেকে অ্যাপ পোস্ট প্রকাশ করে না; কোনো ফলোয়ার, ভিউ, লাইক বা অ্যাকাউন্ট মনিটর করে না। এটি শুধু ম্যানুয়াল কাজের অগ্রগতি ও প্রকাশনার হিসাব রাখে।
