# SalimGPT Command Center — সকল পৃষ্ঠার পূর্ণ তালিকা

**সংস্করণ:** GitHub Native Edition v2.0.0  
**মোট প্রধান স্ক্রিন:** ১৫টি। **ডকুমেন্টারি বিস্তারিত ট্যাব:** ৩টি।  
**অ্যাপের প্রকৃতি:** Single Page Application — `index.html` ফাইল থেকে সব পৃষ্ঠা দেখা যায়; প্রতিটি স্ক্রিনের জন্য আলাদা HTML ফাইল নেই।

## Documentary Studio-এর ভিতরের ৩টি ট্যাব

| ট্যাব | উদ্দেশ্য |
| --- | --- |
| `Production Workflow` | Planning, Research, Scripting, Narration, Visual, Editing, Final Review; প্রতিটি পর্যায়ের Done টাস্ক |
| `Publishing Monitor` | কেন্দ্রীয় Profile Registry থেকে সব সক্রিয় গন্তব্যের তালিকা; Done/Not Published/Not Applicable; প্রকাশনার URL, তারিখ ও নোট |
| `Research & Notes` | ডকুমেন্টারির Brief, উদ্দেশ্য, তথ্যসূত্র, গবেষণা নোট, ভাষা, সময়সীমা |

## কেন্দ্রীয় তালিকা — স্বয়ংক্রিয় প্রকাশনা চেকলিস্ট

- Registry-তে নতুন YouTube channel বা ওয়েবসাইট যোগ করলে সেটি **প্রতিটি ডকুমেন্টারির** Publishing Checklist-এ তাৎক্ষণিকভাবে দেখাবে।
- Publishing status **ডকুমেন্টারি + প্রোফাইল** জোড়ার জন্য আলাদাভাবে সংরক্ষিত হয়।
- Not Published হলো ডিফল্ট; পরে Done করলে Published হিসেবে থাকবে। অন্য ডকুমেন্টারির তথ্য অপরিবর্তিত।
- Profile Archive করলে পূর্বে রেকর্ড করা প্রকাশনা ইতিহাস মুছে যায় না।
- এটি **ম্যানুয়াল মনিটরিং**, অ্যাপ নিজে কোথাও ভিডিও/পোস্ট প্রকাশ করে না।

## ব্রাউজার ডেটা মুছলে পুনরুদ্ধার

`Settings → Verify & Connect GitHub → Sync Now`। আগে GitHub-এ সফলভাবে সেভ হওয়া ডেটা ফিরে আসবে; **Pending GitHub > 0** থাকলে সেই অংশ হারাতে পারে। নতুন সেশনে GitHub Token আবার প্রবেশ করতে হবে।
